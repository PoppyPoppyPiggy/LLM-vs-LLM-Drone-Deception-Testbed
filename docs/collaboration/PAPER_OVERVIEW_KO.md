# 논문 큰그림과 현재 증거

연구 질문은 계층형 군집에서 허니드론의 배치 계층과 정책이 임무 기능 보존에 영향을 주는가이다. L0 관제–L1 리더–L2 중계–L3 임무 구조에서 유인, 접촉 후 상호작용, 실제 기능 상실, 임무 수행 결과를 분리한다.

주 지표는 고정 시간 동안의 mission-capacity AUC다. 임무 완료율을 보조 결과로, 미끼 첫 선택과 접촉 후 체류를 기전 지표로 둔다. 첫 선택이나 단순 상태 변경을 보호 성공으로 환산하지 않는다.

한 블록은 no-Honey 1조건과 static/rule/LLM-no-RAG/LLM+RAG × L1/L2/L3 12조건, 총 13조건이다. 같은 블록 안에서 비교하며 LLM 효과는 정적·규칙 정책 대비, RAG 효과는 같은 모델의 no-RAG 대비로 구분한다.

2026-09-09 파일럿은 2블록·26조건이다. 저장된 감사는 PASS지만 확증 분석은 불가 상태다. L1의 유인은 정적·규칙 정책에서도 나타났고 LLM/RAG의 우월성은 입증되지 않았다. 현재 backend는 HTTP 기능 에뮬레이터이며 실기체 비행·물리 RF 성능을 검증한 결과는 아니다.

본문은 문제와 위협모형 → 계층·측정 구조 → 구현 및 측정 검증 → 비교 실험 → 결과와 비용 → 한계와 재현성 순서로 구성한다. 긍정적 효과를 결론으로 정해 놓고 실험을 변경하지 않는다. 기존 v8 null 결과와 현재 계층형 pilot은 서로 다른 연구 이력으로 유지한다.

다음 연구 작업은 최소 관심효과의 근거, 표본수, 제외·중단 규칙과 다중 비교 계획을 고정하는 것이다. 두 블록의 분산만으로 본실험 표본수를 확정하지 않는다. 이 PR은 본실험을 시작하거나 사전등록 잠금을 해제하지 않는다.

개발 자동화는 출처 기록, 오프라인 분석 코드, 문서와 검사에 적용한다. 생성된 코드나 통과한 CI 자체를 논문 효과의 증거로 사용하지 않는다.
